AI伴读"该不该等"完整分析报告

识别"该给学生思考时间"的题 · 2-6年级15节课·114个小问 · 小鹿斑比伴读4先行试点,整体统一分析
目录 一、背景与目标 二、数据来源与口径 三、判定方法 四、方法奠基(斑比4) 五、整体结论 六、解法 七、新题冷启动预判 八、全部题目明细

一、背景与目标

现状：AI伴读一节课约10-15个互动小问,AI老师提完问,呼吸灯几乎立刻亮起表示"收音中"(零缓冲),麦克风一直开到5分钟超时或学生手动关。技术上不存在"打断",但没有"先想想"的缓冲阶段,呼吸灯的即时催促感会让部分学生一被问就急着开口。

问题:不管什么题都零缓冲,但有些题(如"推断人物心理""设想下次怎么做")本就需要组织时间。一刀切让"该深想的题"受了压,也让"秒答题"没必要地一致。

目标:识别"该给学生思考时间"的题(题目固有属性,不由学生个体反推),为它们在"AI说完→呼吸灯亮"之间插入思考缓冲/提示阶段;秒答题保持零缓冲。

二、数据来源与口径

2.1 数据来源

  • lesson4(小鹿斑比第4课,二年级):行级明细表(约540人×15小问),开口秒数来自开麦埋点(dwd_tutor_frog_di),回答正文来自聊天记录表。这是深挖样本。
  • 99题(3-6年级):从15节课(L2-L6每年级随机抽课、跨不同书、真实作答≥300人次)共118小问中,剔除二年级19小问(避免与lesson4同年级重复)后的 99个小问。慢答来自旧报告已算的开口秒数;沉默/无措/长答来自对话明细表 ods_tutor_ai_reading_chat_detail_for_admin_da,每个学生每小问只取首轮(第一次开口),与lesson4行级粒度一致。
  • 出题人意图:题目配置表 ori_tutor_ai_reading_question_da 的 extra 字段(出题人手写的"问题意图")。

2.2 四个信号的口径定义

① 慢答率(时机)
开口秒数 > 阈值 的学生占比。开口秒数 = 从AI说完到学生开口第一个字的时间(含1-2秒链路采集延迟,故偏大)。给 >5秒 / >6秒 / >7秒 三档:从5秒到7秒掉得慢=真慢扎实,掉得快=慢是延迟灌的。各年级设不同门槛(2年级24.3% / 3年级22.7% / 4年级21.7% / 5年级25.1% / 6年级34.1%,来自各年级慢答分布的第70百分位)。
② 长答率(篇幅)
全体学生里回答 ≥15字 的占比。15字 = 118题字数分布里"短答/成句展开"的共通分界。
③ 无措率(内容质量)
开口后说"不知道/不会/忘了"等放弃词(≤15字)、纯语气填充(整句嗯呃啊)、重复结巴 的占比。"伤心/勇敢"等有实义短答一律算有效答案,不算无措。
④ 沉默率(流失)
有作答动作/录音但没识别出人声的占比(对话记录里标记"用户未回答")。这批人不在旧行级表里,是之前完全看不见的流失。

三、判定方法(逻辑)

核心:"该不该等"是题目的固有属性,由"出题人意图"和"学生真实行为"共同判定,不由学生个体反推。

3.1 第一层:出题人意图(该等的动机)

读出题人手写的"问题意图",按意图动词归三类:
  • 该等:推断 / 体会 / 设想 / 表达 / 描绘 / 评价 / 概括人物 / 说明理由 / 迁移应用 —— 需要组织加工,不能照抄原文
  • 不该等:提取 / 辨认 / 列举 / 确认 —— 答案在原文里直接可取
  • 中间:梳理 / 对比 / 归因 —— 介于两者

3.2 第二层:学生四信号画像(该等的证据)

慢答(想没想久)× 长答(答得够不够)× 无措(会不会答)× 沉默(有没有流失)——合看一次作答的全貌。

3.3 交叉判定规则 + ★行为否决原则

★ 行为否决原则(关键)

意图和学生行为打架时,若学生明确"秒答+短答"(慢答远低于门槛 且 长答很低),以行为为准,判"不用"。因为优化目的是解决真实问题——学生都秒答了,给缓冲没有意义。光看出题人意图会高估"该等"需求,必须用学生真实行为兜底。

四、方法奠基:小鹿斑比伴读4(二年级·先行试点)

后面114题整体分析用到的所有门槛(5秒、15字、各年级慢答门槛)和判定逻辑,都是先在这一节课上推导、确认的。本章交代它们的来历。

4.1 为什么慢答阈值定"5秒"

把这节课每道题的开口秒数按每1秒一档铺开,看分布形状:典型是2-3秒冲到峰值,之后一路降,过5秒后压得很低拖成长尾。重点看曲线跨过5秒时明显"掉一截"(4-5秒那档明显多于5-6秒那档,像下楼梯踩空一级)——这道坎就是"正常反应"与"偏慢长尾"的天然分界。

以回信题(466170)为例,开口秒数分档占比:

结论(5秒):推广到全部118题验证——116/118题都在5秒后掉台阶,全部118题峰值都在5秒内。说明"5秒"对每道题都成立,不是被个别题凑出来的。慢答阈值 = 开口>5秒。(开口秒数含1-2秒链路延迟,故另给6/7秒看衰减:掉得慢=真慢扎实,掉得快=延迟灌的。)

4.2 为什么长答界定"15字"

把回答字数按分布看:字数四分位 P25=7字 / 中位=16字 / P75=36字。15字正好在中位附近,是"一句短答(嗯/紧张/好的)"与"成句展开(成段说明理由)"的分界。

结论(15字):118题验证——98/118题在15字后字数明显下坠。虽不如5秒那么齐(字数天生比时间散),但15字是绝大多数题共通的短答/展开分界。长答 = 回答≥15字。

4.3 各年级慢答门槛怎么来的

"多少慢答占比算需要优化"不能一刀切——每个年级学生反应速度不同。做法:把每个年级所有题的慢答占比从高到低排,取相对靠前三成的位置(第70百分位)作为该年级门槛。慢答占比高过本年级门槛的题,才算"慢的人明显偏多"。

4.4 判定逻辑:意图 × 学生行为

"该不该等"是题目固有属性,由两层共同判定:

  • 出题人意图(动机):读题目配置里出题人手写的"问题意图"。推断/设想/表达/概括=倾向该等;提取/辨认=倾向不该等。
  • 学生四信号(证据):慢答(想没想久)、长答(答得够不够)、无措(会不会答)、沉默(有没有流失)。

lesson4先用"意图为主"判,但随后发现一个盲区——有的题出题人意图想让学生深想,可学生实际慢答很低(不需要时间)。若只看意图会误判。于是确立最终规则:

★ 判定核心(在lesson4确立,用于全部114题)

慢答率过门槛 = 该等的硬门槛(确有一批学生在花时间想)。长答只决定该等题给缓冲(A类,长答≥40%)还是配支架(B类,长答<40%)。慢答没过门槛的,不管长答多高,都判不用——因为学生根本不需要时间。无措率≥6%的另标"卡壳型"(该等且需配提示)。

结论1 · 约三成半题该给思考时间

114题中 40道(35%)判"该等"——慢答率过门槛(确有一批学生需要时间组织)的题。其余54%"不用"(慢答未过门槛,学生不需要时间),保持零缓冲即可。

结论2 · 该等题分两类,优化动作不同

40道该等题:A类21道(真慢深答,长答≥40%)→直接给思考缓冲;B类19道(想深答短,长答<40%)→愿花时间想却组织不出长答,光给时间不够,需配表达支架(给句式/例子)。

结论3 · 11道"边缘题"待人工再看

有11道慢答率刚好差门槛≤2个百分点,卡在该等与不用之间(不少长答还很高,如"感悟主旨"长答83%)。归为"留意",建议结合题目具体判,不硬分类。

结论4 · 意图不能单独定,须用学生行为兜底

分析发现:不少题出题人意图想让学生深想,但学生真实数据是慢答低(不需要时间)。判定以慢答率为硬门槛——只看出题人意图会高估该等需求,给这些题加缓冲只会拖慢答得快的大多数。

七、新题怎么办:冷启动预判

前六章的判定都依赖学生数据(慢答率)。全新题目上线时没有任何学生数据,只能靠题目侧信息预判。本章给出可用的预判依据和它的可靠性边界。

先说结论:纯题目信息不能"判定",只能"预判倾向"

我们做了回测——假装没有学生数据,只用题目信息(出题人意图/题干文本)去预测"学生是否真的慢答"。结果:要么漏过多(漏43%该等题),要么误伤高(误伤79%),没有平衡点。根本原因:"题目看起来该深想"和"学生实际会花时间想"相关性弱——同一道推断题,有的学生深想、有的秒答,取决于学生和课堂,不只是题目。所以新题预判只能做冷启动倾向,不能替代上线后的真实数据。
